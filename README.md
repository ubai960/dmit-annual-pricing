说年付好，不代表月付就没用。下面这几种情况，月付反而更合适。

**第一，需求还没定下来。** 你不确定自己要建站还是搭节点，不确定用洛杉矶还是香港，那就先月付一个月试试。DMIT支持3天退款，但如果你可能用到第二周、第三周才摸清楚，月付的灵活性就体现出来了。

**第二，需要更高配置但年付没有对应款。** 年付WEE款普遍是1核1G的入门配置，如果你要2核2G、4核4G这种中高端配置，年付专属款里基本没有，只能走月付或者季付。比如LAX.Pro.STARTER（2核2G/80G/3T/10Gbps）月付 $29.90，这种配置就只能月付或季付走。
